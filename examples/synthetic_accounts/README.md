# 十套模拟交割单 —— 按行为画像构造的合成账户

**全部是合成数据。** 证券代码真实存在，但名称、价格、每一笔成交均为构造值，
不代表任何真实行情或真实交易。这套数据的用途有两个：

1. **引擎压力测试**：十种交易结构（拆单、T+0、送转、单侧无机会……）
   全部通过 FIFO 配对、T+1 校验与期末价一致性自检；
2. **报告画廊**：每套跑出来的报告结论各不相同，比单一样例更能说明
   "同一套口径在不同行为下会说什么话"。

为什么不是随机生成：纯随机的买卖记录会让 PGR/PLR 收敛到无意义的中间值，
十份报告长得一样。这里每套数据围绕一种**真实存在的散户行为画像**构造，
赢家/输家的持有期与期末持仓的盈亏状态都被刻意设计。

## 这张表本身在讲四件事

**一、方向会骗人，区间不会。** p10（无模式基线）期末口径 DE −13.2%、
滚动口径 +5.2% —— 同一个账户两种口径方向相反，而且显著性检验都说不显著。
这就是"别看方向、看置信区间"的活教材。

**二、DE 大不等于有结论。** p04 学生账户 DE +79.6% 比样本账户（+18.4%）
大得多，但每侧只有 4 个机会，判定直接写"样本太小，请以置信区间为准"。
引擎宁可拒绝给方向，也不给一个听起来漂亮的判断。

**三、"单侧无机会"是真实存在的账户形态。** p07 转债 T+0 全是当日止盈
（从未割肉）、p09 熊市死扛从未在盈利状态卖出 —— 这类账户 PGR 或 PLR
在数学上就是空的。报告的措辞是"这本身是信息：你没有『落袋』行为"，
而不是硬编一个数。

**四、定投型呈"反向"不奇怪。** p06 大部分浮盈从不止盈（分母里躺着），
唯一卖出的那笔是止损 —— DE 自然为负。这恰恰说明 DE 度量的是
"兑现节奏的差"，不是"这个人水平如何"。

## 文件结构

```
p01_chase_sell/            交割单 CSV（目录内只有交割单，运行时整目录传入）
  ├─ p01_..._ths.csv       同花顺风格：UTF-8 BOM、抬头两行、负数卖出、包干手续费
  └─ README.md             该人格的说明卡
p01_chase_sell_price_history.csv   逐日收盘价（供 --price-history，放在目录外）
reports/p01_chase_sell.html        已生成的报告（画廊）
generate.py                生成器（seed 固定，重跑逐字节一致）
```

格式分布：p01/p03/p04/p07/p09 同花顺风格单文件；p02/p05/p08 华泰风格
（GB18030、费用三列）；p06/p10 两种格式年中拼接（演示分月导出）。

## 生成时卡死的四条一致性（不通过直接报错）

1. 全部成交落在工作日；
2. 股票/ETF 不违反 T+1（可转债 11/12 开头豁免；同标的的买卖日期
   通过 `Book` 簿记强制错开 —— T+1 校验是"卖出当天只要存在买入就报警"）；
3. 任何一笔卖出不超过当时持仓；
4. 给了期末价的标的期末必有持仓、没给的必已清仓 —— 价格序列与账本互证。

## 已知边界

- 价格是"锚点 = 成交价 + 区间插值 + 端点归零正弦扰动"的构造值，
  **没有除权跳空**（10 送 3 当日价格无跳变）。滚动口径对除权的正确性
  仍未被示例数据验证过，见 ROADMAP 技术债务。
- p10 出现了同标的时间窗重叠的往返（FIFO 跨轮配对），是无模式账户的
  合理形态，但也意味着它的已实现笔数不完全等于设计的轮数。
