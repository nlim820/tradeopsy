# 示例账户（合成数据）

> **这不是任何真人的交割单。** 全部记录由 `generate.py` 确定性生成，
> 不含真实的账户、姓名、资金或持仓信息。使用它不需要任何隐私授权。

## 为什么仓库里要有这份数据

tradeopsy 的定位是"体检**你自己的**交割单"。但真实交割单涉及隐私，不可能进公开仓库。
结果是：任何人打开这个仓库，只能看到一句"请把你的 CSV 放进来"，
无法验证这个工具是否真的能处理券商导出的脏数据。

这份示例账户就是为了补上这个缺口：它把"真实交割单有多脏"这件事，
用可公开、可复现、可测试的方式固定下来。

它同时是 `tests/test_sample_account.py` 的输入 —— 也就是说，
**这份数据的解析结果被测试钉死了**，不是摆在仓库里看的摆设。

## 文件清单

| 文件 | 说明 |
|---|---|
| `generate.py` | 生成器。无随机数，重跑结果完全一致；自带工作日 / T+1 / 超卖三重自检 |
| `part1_2025-11_2026-03_ths.csv` | 上半段。**同花顺风格**：UTF-8 BOM、抬头占 3 行、负数表示卖出、单列"手续费"包干 |
| `part2_2026-04_2026-10_ht.csv` | 下半段。**另一家券商风格**：GB18030 编码、费用拆成净佣金/印花税/过户费三列、正数表示卖出、列顺序不同 |
| `../sample_account_prices.csv` | 2026-10-30 收盘价（构造值），供 `--prices` 计算未平仓市值 |

拆成两份不是随意为之：真实用户往往按月或按半年导出，拼接后才是一整年。
两份格式不同，正好把解析层的**编码嗅探、表头定位、列名模糊匹配、费用分项合并**
整条链路跑一遍。

## 数据里刻意埋的坑

| 场景 | 出现在 | 为什么容易算错 |
|---|---|---|
| GB18030 编码 | 下半段整个文件 | 按 UTF-8 读会解码失败；按 `errors="ignore"` 会把证券名称吃成空串 |
| 表头不在第 1 行 | 两个文件 | 抬头有"资金账号""查询区间"，硬编码 `header=0` 必崩 |
| 费用拆三列 | 下半段 | 同时存在包干列和分项列时若都累加，会重复计费 |
| 负数表示卖出 | 上半段 | 数量取绝对值后必须保留方向，否则卖单变买单 |
| 10 送 3（红股入账） | 五粮液 2026-06-05 | 股数 1000→1300、总成本不变；只看价格会误判为亏损 |
| 配股缴款 | 招商银行 2026-05-15 | 掏钱换新股，总成本增加、每股成本重新摊薄 |
| 可转债 T+0 | 南银转债 | 当天买当天卖，持有 0 天；A 股 T+1 规则对它不适用 |
| ETF 免印花税 | 沪深300ETF | ETF 卖出也按千 0.5 收税，一年多算的成本足以让收益率对不上 |
| 打新中签 | 中国电信 2026-04-09 | 股份到账但没有"买入"成交价，成本要按发行价认定 |
| 无法识别的业务 | 担保品划转、利息归本 | 正确行为是**告警并继续**，不是整批失败 |

## 一条命令复现

```bash
cd D:/projects/tradeopsy
PYTHONPATH=src python -m tradeopsy analyze examples/sample_account \
    --prices examples/sample_account_prices.csv
```

跑出来的关键结果（确定性，可核对）：

- 66 条有效事件、14 只标的、25 笔已实现、15 个未平仓批次
- 已实现价差盈亏 **+23,164.90** 元，现金分红 **+10,500.00** 元
- 2 条告警（担保品划转、利息归本），解析未中断
- PGR 58.48% / PLR 40.05% → 处置效应 **+18.43%**（金额口径）
- 计数口径 PGR 74.07% / PLR 38.46% → DE **+35.61%**，bootstrap p=0.031
- 赢家平均持有 **52.1 天**，输家平均持有 **147.8 天**

最后一行才是这份数据真正想表达的东西：**赚了就跑、亏了死扛**，
在一年的时间里表现为"赢家拿得比输家短三个月"。
这不是我们往报告里写的结论，而是从流水里算出来的。

## 重新生成

```bash
python examples/sample_account/generate.py
```

生成器会先自检三件事，任一不满足直接报错而不是写出脏数据：
1. 所有日期必须是工作日；
2. 股票 / ETF 不得当日买入当日卖出（T+1），可转债豁免；
3. 卖出数量不得超过持仓。

改完生成器后记得同步 `tests/test_sample_account.py` 里的预期值 —— 它会红。

## 已知近似（诚实交代）

- **节假日未精确剔除**。只排除了周末，未剔除春节、国庆等休市日。
  对账本正确性无影响（账本不依赖交易日历），只影响"持有自然日"的显示。
- **费率取常见档位**：股票佣金万 2.5（最低 5 元）、印花税千 0.5、过户费万 0.1；
  ETF 佣金万 1、免印花税；可转债佣金万 1、无最低。你的实际费率可能不同。
- **公司行为是构造的**。真实的送转比例、分红金额、配股价格以公告为准，
  这里仅为演示"账本能正确处理这类事件"，不代表任何真实公司的实际方案。
